# VaultCova for Windows

Download the current Windows app from the [releases page](../../releases/latest).

- Run `VaultCova-1.0.0-windows.exe` - no installation needed.
- Passkey sign-in uses Windows Hello (face / fingerprint / PIN) natively.

Note: the download is not yet code-signed, so Windows SmartScreen may ask you
to confirm - choose "More info" -> "Run anyway".
